# R5：候选四元临界系统的严格有理 Krawczyk 隔离

日期：2026-08-19

## 0. 结论

这一步已经严格闭合。

令现有精确整数多项式为

\[
P_1(x,y,z,g),\quad P_2(x,y,z,g),\quad P_3(x,y,z,g),
\]

并令

\[
J=\det\frac{\partial(P_1,P_2,P_3)}{\partial(x,y,z)},
\qquad \mathcal F=(P_1,P_2,P_3,J).
\]

配套程序用端点均为 `Fraction` 的闭区间，严格证明：在本报告给出的
显式有理盒 (B\subset\mathbb R^4) 中，

\[
\boxed{\mathcal F(x,y,z,g)=0}
\]

恰有一个实零点。证书同时证明所有候选矩阵重构分母非零、第二和
第三主元为正，并把 (g) 坐标限制在已认证的 61 次多项式根区间
(I_\alpha) 内。

本轮没有使用 Lean。高精度浮点 Newton 只负责产生盒中心；存在性和
唯一性判定完全由有理数区间运算完成。

## 2. 证书的数学形式

取盒中点 (m\)，并在有理数域中精确计算

\[
C=\mathcal F'(m)^{-1}.
\]

程序执行精确 Gauss--Jordan 消元；所以成功构造 (C) 本身也证明
(\mathcal F'(m)) 非奇异。对整个盒的 Jacobian 区间包络
(\mathcal F'(B))，计算 Krawczyk 像

\[
K(m,B)=m-C\mathcal F(m)
       +\bigl(I-C\mathcal F'(B)\bigr)(B-m).
\]

端点整数的精确比较给出

\[
\boxed{K(m,B)\subset\operatorname{int}B}.
\]

此外，程序对矩阵区间 (I-C\mathcal F'(B)) 的每一行取绝对值上界之和，
并以精确分数验证

\[
\boxed{
\sup_{M\in I-C\mathcal F'(B)}\|M\|_\infty<1.
}
\]

它的十进制量级约为 (6.51901\times10^{-175})。因此 Krawczyk 包含给出
盒内零点存在，收缩估计给出盒内零点唯一；这里并未只依赖一个数值
Newton 收敛轨道。

作为证书强度的诊断，四个 Krawczyk 像宽度与原盒宽度之比分别为

| 坐标 | `width(K_i)/width(B_i)` |
|---|---:|
| (x) | (4.02224\times10^{-175}) |
| (y) | (2.39845\times10^{-175}) |
| (z) | (6.12934\times10^{-175}) |
| (g) | (3.60552\times10^{-156}) |

这些小数只是便于阅读；程序中的包含和收缩检查使用未舍入的分数。

## 3. 为什么没有展开 5059 项的 (J)

直接展开 (J) 会产生 5059 个单项式。程序保留

\[
A_{ij}=\frac{\partial P_i}{\partial(x,y,z)_j},\qquad J=\det A,
\]

并利用行列式对行的多线性：

\[
\frac{\partial J}{\partial v}
=\sum_{i=1}^3
\det\bigl(A\text{ 的第 }i\text{ 行替换为 }\partial_v A_{i,*}\bigr).
\]

所以只需区间求值 (P_i) 的一、二阶导数。这既是精确恒等式，也减少
表达式膨胀和自然区间扩张造成的依赖损失。

## 4. 重构分母认证

在唯一根盒上，配套程序对重构公式逐项作有理区间求值。以下是便于
阅读的包围；底层端点仍是精确分数：

| 因子 | 严格包围 | 结论 |
|---|---:|---|
| (y) | ((-0.780,-0.779)) | 非零 |
| (x+1) | ((0.382,0.383)) | 非零 |
| (1+z=p_2) | ((1.453,1.454)) | 正 |
| (D_T=2x^2z+xz^2+xz-2x-2) | ((-0.827,-0.825)) | 非零 |
| (T=a_{42}) | ((0.635,0.636)) | 重构坐标已界定 |
| (y-T) | ((-1.416,-1.414)) | 非零 |
| (y(y-T)) | ((1.102,1.103)) | 非零 |
| (p_3) | ((2.074,2.075)) | 正 |

这里 (T=a_{42}=N_T/D_T)。这张表覆盖

- (a_{13}=-z/y)；
- (a_{15}=z(x+z)/(x+1))；
- (T=N_T/D_T)；
- (a_{23},a_{33}) 的分母 (y(y-T))；
- 第二、第三 Schur 消元所需的非零主元。

因此唯一临界元组不落在求解等式时引入的任何分母异常层上。

## 5. 与 61 次代数数的识别

同一脚本重新执行了整数系数 Horner 求值和精确 Sturm 计数，得到

\[
\operatorname{sign}P_5(L)=-1,\qquad
\operatorname{sign}P_5(U)=+1,
\qquad N_{[L,U]}(P_5)=1.
\]

Krawczyk 盒的 (g)-投影正好就是 ([L,U]=I_\alpha)。结合已经独立重算
的消元链：临界系统使 (P(z,g)) 关于 (z) 出现重根，从而使其判别式
为零；而精确因式分解为

的非恒定不可约因子恰为

\[
g-8,\quad P_5(g),\quad g-6,\quad g^2-12g+40,\quad g-2,\quad g-4,
\]

各自带正整数重数并乘一个非零有理常数。在 (I_\alpha) 上除
(P_5) 外的所有显示因子均
严格非零；上一节又排除了重构/饱和分母异常。因此唯一临界元组满足

\[
P_5(g)=0,
\]

并由根隔离唯一性得到

\[
\boxed{g=\alpha}.
\]

这里使用的消元多项式和判别式因子可在
`work/P_zg_singular.txt` 与 `work/singular_discriminant_factors.txt`
中逐项审计。本模块没有重新生成那条已经完成的 Singular 消元链。

## 6. 对 R4 局部等振证书的影响

本盒严格包含在 R4 使用的粗盒

\[
x\in[-0.618,-0.617],\quad y\in[-0.780,-0.779],\quad
z\in[0.453,0.454],\quad T\in[0.635,0.636].
\]

因此 R4 中八个活动 circuit 的有理符号判定，现在确实适用于一个已经
证明存在且唯一的代数临界元组，而不再只是“假设数值候选位于粗盒中”。

这一步证明的是：候选等式模式中有唯一临界点，且其值为 (\alpha)。
它仍不单独证明该点对所有活动模式局部最优，更不替代全局盒覆盖。

## 7. 新增的八维正依赖目标

主线程提出的下一项局部目标——六个活动 circuits 加三个边界法向量的
八维正依赖、非零 (8\times8) minor——没有混入本证书。原因是它属于
固定 (C_*) 的 nonsmooth KKT 模块，而不是四元代数根隔离本身。

本报告产生的 (10^{-180}) 根盒已经为该模块提供了足够窄的精确参数盒。
下一独立模块可以直接对所选 minor、九个系数的正性和剩余梯度关系做
有理区间认证，不必再次寻找候选点。
