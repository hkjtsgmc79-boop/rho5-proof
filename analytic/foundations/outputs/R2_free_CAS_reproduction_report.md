# R2 收尾：61 次多项式的免费 CAS 独立复现

日期：2026-08-16  
结论：**已完成。** 本轮不依赖 Mathematica 的中间输出，以论文候选矩阵和紧等式为输入，用 SymPy 重建精确方程，再用 Singular 完成 Gröbner 消元、判别式分解和 61 次因子提取。

## 1. 固定输入

- 论文/仓库：`jamiecjx/growth-5x5`
- 审计 commit：`bd6d13af571d0c454178dac24e753f7cac7a3727`
- 原始输入：官方 `n=5_discriminant.nb` 中的 5×5 候选矩阵、4 个 F 等式、3 个 G 等式、1 个 H 等式，以及最后 2 个 H 等式和增长等式。
- 免费工具：SymPy 1.14.0；Singular 4.4.1（Conda-forge 构建 `hf33d76d_3`）；GMP 6.3.0；NTL 11.6.0；FLINT 3.3.1。

## 2. 独立重算路径

1. 从 5×5 矩阵直接计算三次 Schur 补，不复制 Notebook 的 `p1,p2,p3`。
2. 按 F → G → H 的阶段顺序精确求解 8 个后续坐标。
3. 清分母时出现形式分支 `a42 = y`；该分支使上一阶段解式的分母恒为零，已显式排除。
4. 得到三个整数多项式：
   - 项数：169、216、193；
   - 总次数：14、15、12。
5. 在 Singular 中使用块序
   `ring r = 0,(y,x,z,g),(lp(1),dp(3));`
   消去 `y`。这避免了纯字典序的严重中间膨胀。
6. 将三变量消元理想转换为 `(x,z,g)` 的字典序三角基并分解；按数学性质而非因子位置，唯一选出
   `(deg_z,deg_g)=(10,7)` 的因子 `P(z,g)`。
7. 计算 `resultant(P,dP/dz,z)` 并在 `Q[g]` 上分解。结果共有 6 个非恒定因子：
   - `g-8`
   - `g-6`
   - `g-4`
   - `g-2`
   - `g^2-12g+40`
   - 唯一的 61 次因子 `P5(g)`

## 3. 61 次因子核对

Singular 独立得到：

- 次数：61；
- 非零系数：62；
- 首项系数：59049；
- 常数项：
  `-400768351683901408958416200638054732473753927680`；
- 系数 content：1；
- Singular 的有理数域分解没有继续拆分该因子。

随后从官方 Mathematica Notebook 的 `Out[12]` 单元另行解析全部 62 个系数，与 Singular 结果按次数 0–61 逐项比较：

```text
notebook_coefficients = 62
singular_coefficients = 62
exact_match = true
differences = []
```

因此，免费 CAS 路线已经独立重算出论文的完整 61 次多项式。

## 4. 根隔离复核

对先前给出的宽度 `10^-200` 的有理区间 `[L,U]`，使用整数系数 Horner 求值和精确 Sturm 根计数：

```text

sign(P5(U)) = +1
number of roots in [L,U] = 1
```
