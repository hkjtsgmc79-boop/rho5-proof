# v1.0.0 — first public source and certificate release

This release publishes the first-phase Lean analytic assembly (646 canonical source modules), exact computational archives and their frozen verifier sources, the manuscript and supplementary index, and step-by-step verification/download documentation.

The original large historical-root archive is distributed in five transport parts. `scripts/fetch.py` verifies each part and restores the original archive hash. Other certificates retain their original archived bytes. Upstream canonical, reconstruction, entrance and X/B reduction packages are included separately.

The Lean sharp endpoint keeps the original XGlobalSafety and RootEndpointSafety hypotheses. The external checker implementations are not formally verified. Recorded component acceptances are preserved, but this publication does not assert a new-machine Lean cold build or a new all-components mathematical replay. The guide documents the existing exact commands and final-composition portability limitations.

Authors: Qianli Ma and Chao Wu. Zenodo archival will follow; no DOI is claimed here.
