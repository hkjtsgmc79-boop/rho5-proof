## Reproduction order

1. Fetch and SHA-check the inherited `b` archives using `python3 scripts/fetch.py --group b`. Preserve the original archive bytes. Extract `historical_root.tar.gz` and `final_cover.tar.gz` under a chosen Linux source workspace, retaining the historical directory structure and metadata members.
2. Obtain the [fixed replay supplement](https://github.com/hkjtsgmc79-boop/rho5-proof/releases/download/v1.0.2/RHO5_v1.0.2_replay_evidence.zip). Check its published SHA-256 and read `PUBLIC_SOURCE_ASSEMBLY_PLAN.json` before running producers. Its preparation script expects four extracted historical directories and an empty task directory **inside** the chosen source workspace. It does not download or extract the large archives itself.
3. Run `prepare_remote.py` with `--sources` pointing at that source workspace and `--workspace` pointing at its new task directory. Build the sealed plan and inspect its source/target identity gates. Only after all required inputs match should mathematical replay begin.
4. Run the original-root checker and 570 producer tasks with assertions enabled. They may run concurrently if the machine has sufficient resources. Compose only after the root and all required producers pass. The documented command order and supported worker parameters are in the supplement's completed replay status; keep a distinct output directory.
5. Retain the exit codes, exact receipts and environment details. `FRESH_FOUR_PARENT_AND_ORIGINAL_ROOT_COMPOSITION_ACCEPTED` with four bound original OPEN records and `effective_open_count = 0` is the final finite-cover result. File identity alone is insufficient.

**Public-source portability status:** the fixed archives and exact source-root mapping are identified, and the replay ZIP's own receipt/link checks passed. A [selective clean assembly and entry-point preflight](../provenance/v102_assembly_preflight/README.md) additionally extracted 706 SHA-pinned members directly from the two verified public archives and reproduced the 570-job, 566-target plan; the generated dependency manifest differed from the sealed one only in its creation time. Disk space did not permit a second full extraction of both archives. This preflight did not execute the 570 producers or the original-root verifier, and it is not a tested portable end-to-end replay of the entire theorem. The full theorem's upstream X and analytic dependencies have a separate, broader reproduction scope.
